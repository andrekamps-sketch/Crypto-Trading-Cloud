CRYPTO TRADING ZENTRALE V6.4 CLOUD – KURZANLEITUNG
==================================================

V6.4 erweitert V6.3 um Telegram-Benachrichtigungen. Die bestehende Railway-Volume /data
bleibt vollständig kompatibel. Beim Update werden die eingefrorenen V5.2-/V6-States nicht verändert.

UPDATE VON V6.3 AUF V6.4
------------------------
1. ZIP entpacken.
2. Den INHALT dieses Ordners in dasselbe GitHub-Repository-Hauptverzeichnis hochladen.
   Vorhandene Dateien ersetzen/überschreiben.
3. Commit changes.
4. Railway deployed automatisch neu (oder einmal Redeploy drücken).
5. Das bestehende Volume mit Mount Path /data NICHT löschen.

TELEGRAM EINRICHTEN
-------------------
1. Telegram öffnen und @BotFather suchen.
2. /newbot senden und einen Bot anlegen.
3. Den Bot-Token kopieren.
4. Railway -> Service -> Variables -> New Variable:
   TELEGRAM_BOT_TOKEN = <dein Bot-Token>
5. Änderung deployen.
6. Deinen neuen Bot in Telegram öffnen, Start drücken und z.B. "Hallo" senden.
7. Cloud-Zentrale öffnen -> Tab "Benachrichtigungen" ->
   "Chat-ID automatisch finden & speichern".
8. "Testnachricht senden" drücken.
